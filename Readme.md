# Experiment

An experimental project focused on rapid prototyping and exploratory features.

---

## Overview

**SpyX** is a research and prototyping repository designed to test, validate, and iterate on experimental features, user interfaces, and architectural patterns.

---
## Getting Started

### Prerequisites

Ensure you have the following installed on your system:

- [Git](https://git-scm.com/)
- Node.js (v18+) or Python (3.10+), depending on the experimental modules being run.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/arthemisz/Experiment.git
   cd SpyX
   ```

2. **Set up the environment:**
   ```bash
   # If using Node.js:
   npm install

   # Or if using Python:
   python -m venv venv
   source venv/bin/activate  # On Windows: .\venv\Scripts\activate
   pip install -r requirements.txt
   ```

---

## Usage

Run the primary prototype or development server:

```bash
# Start development / experiment runner
npm run dev
# or
python main.py
```
